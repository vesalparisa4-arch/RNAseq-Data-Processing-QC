# Transcriptomics: RNA-seq Processing and Quality Control
Computational Biomedicine, Tutorial 4 (part 2). Mouse mammary-cell gene expression (GSE60450): metadata matching, sample-label correction, library size checks, CPM filtering, boxplots and MDS using edgeR and limma. Exports filtered counts and corrected sample metadata as RDS for follow-up analysis.

## Run
Place authorized `GSE60450_Lactation-GenewiseCounts.txt`, `SampleInfo.txt` and `SampleInfo_Corrected.txt` in `data/`. Run `Rscript analysis.R`. This is the QC portion extracted from the original Tutorial 4 code. No new R run was performed; check outputs and permissions before publishing.
